# AstroLog — Реєстр космічних місій

Односторінковий React-застосунок (SPA) для обліку та аналізу космічних місій із власним керуванням станом через `useContext` + `useReducer`, маршрутизацією (`react-router-dom`) та кастомною валідацією форм.

## Предметна область
- **Головна сутність:** Космічна місія (13 полів різних типів)
- **Зв’язок багато-до-одного:** Космічне агентство (`NASA`, `ESA`, `JAXA`, `SpaceX`, `ISRO`, `ДКАУ / КБ «Південне»`)
- **Зв’язок багато-до-багатьох:** Наукові прилади (7 позицій, мультивибір через `react-select` із пошуком за початком назви)

## Запуск проєкту
```bash
npm install
npm run dev
```

Інші команди:
- `npm run build` — продакшн-збірка у `dist/`
- `npm run lint` — перевірка коду через `oxlint`
